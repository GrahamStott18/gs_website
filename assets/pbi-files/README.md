# Power BI Project Files

This directory contains downloadable Power BI project files (.pbip format).

## Files Description

### sales-analytics.pbip
- **Purpose**: Executive sales dashboard with KPI tracking
- **Data Sources**: SQL Server, Excel files
- **Last Updated**: March 2024
- **Version**: Power BI Desktop March 2024

### supply-chain.pbip
- **Purpose**: Global supply chain visualization
- **Data Sources**: Azure Data Lake, API endpoints
- **Last Updated**: February 2024
- **Version**: Power BI Desktop February 2024

### healthcare-dashboard.pbip
- **Purpose**: Patient care analytics platform
- **Data Sources**: FHIR API, Hospital Database
- **Last Updated**: January 2024
- **Version**: Power BI Desktop January 2024

## Usage Instructions

1. Download the .pbip file
2. Open with Power BI Desktop (March 2024 or later)
3. Update data source connections as needed
4. Refresh data to see latest visualizations
